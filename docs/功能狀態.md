# 功能狀態與限制

更新日期：2026 年 11 月 26 日（原始碼與公開 Release 已更新至 **V4.3 SLEM (`hany`)** 雙版本 `With Touch / With no Touch` ＋ **V4.3 Sound Lite**；歷史效能單張比較基準同步附列 **V3.9 SSLF** 與 **V3.5.1 Fast SP**）。這份狀態描述在測試機（Sony ILCE-6400 FW 2.00，並經社群於 ILCE-6100 與 ILCE-6600 跨機型實證）上的實測範圍與工程邊界。

## V4.3 SLEM (`hany`) ＋ Sound Lite 最新驗證與能力總覽

- **雙版本發行與原生 MENU 全觸控（MTF2）**：
  - **`With Touch` 版**：自製選單可觸控，並整合 `mtf2_native_touch.h` 啟用 Sony 原生 `MENU` 全頁觸控、滑動與彈窗點選（採模組相對 RVA ＋ 10 組機器碼指紋驗證，並在進入細節設定時自動重測避免慢載入誤判）。
  - **`With no Touch` 穩定番（`A6400_MTF2_ENABLE=0`）**：自製選單／套色相冊／雙重曝光皆可完整觸控，完全不介入 Sony 原生 `MENU` 觸控，極致穩定。
- **哈蘇 2×2 田字格選單（無自動隱藏）＋ 開機「已就緒」微提示 ＋ 防假死保護**：
  - 取消 20 秒自動隱藏，配置 `LUT 設定`、`套色相冊`、`細節設定`、`畫質`（**`1.7MP 極速` / `6MP 高清` / `12MP 超清 (4240×2826)`** 三段切換）與雙欄 10 款膠片清單。
  - 開機首次掛載進入 UI 時於右上角閃出 1.2 秒綠色提示 `V4.3 SLEM 已就緒`，`animate()` 具備執行緒 `tid` 自癒與 `ticker_layer` 重啟保護。
- **100% 保留原廠回看相簿（`▶`）＋ 原生零閃屏 `RGBA4444` 預覽 ＋ 16 槽位 RAM 秒開套色相冊**：
  - 徹底不挾持 Sony 原廠播放鍵；拍完轉檔完成後右下角自動彈出 `240×160` `GEN_CacheInsImg` 硬體圖層零閃屏即時預覽小窗。
  - **套色相冊（PR #15 ＋ V4.3 LRU 加速）**：改為讀取 SD 卡 `/A6400/TEST/F*.JPG` 最多 `1,024` 筆（拔電池不消失、`448×400` 3:2 比例顯示＋EXIF 自動轉正直拍），配合 16 張 `/tmp_bt/a6400-pv/c_*.bin` LRU 秒開快取、開機預熱最新 1 張、相鄰 4 張預抓、12MP `1/8` DC 極速解碼（`~25 ms`），以及背景讀回 `kill(-pid)` 行程群組回收＋`umount2(..., MNT_DETACH)` 掛載自癒。
- **雙重曝光（DEXP：濾色 Screen / 變亮 Lighten / 平均 Average）**：
  - 固定採用 `1.7MP` 內嵌預覽合成避免 `6MP/12MP` 同時解碼爆 RAM，並與 LUT 嚴格互斥；拍完第 1 張進入 `1/2` 時，首頁右上角自動轉為橘底 **`取消雙曝 1/2`** 一鍵重拍。
- **`gzip` 開機包瘦身 ＋ 慢卡 180 秒掃描 ＋ Windows WSL2 跨版升級同步**：
  - `/tmp/a6400-film-boot-v15.tar` 採 `gzip` 壓縮（`245,760 B` → `116,517 B`、`tar -xzf` 解壓）；常駐模式 `SCAN_MS` 放寬至 `180s` 並過濾 `MPR` 時序除錯行；修復 `wsl_deploy` `sync_deployer_scripts` 延遲展開問題。
- **V4.3 Sound Lite 純淨快門音分支（原始碼建置）**：
  - `build_sound_lite.sh`（`A6400_SOUND_LITE=1`）建置極簡奶油白＋霧黑 Sound Deck UI（10 標籤＋20 面板零延遲、16 槽位、真實 SDS ADPCM 波形顯示、全觸控翻頁／試聽／Hi+ 連拍開關／關閉），支援讀取 SD 卡 **`/A6400/SOUNDS/*.pcm`**（最多 12 個各自綁定獨立 Sony APP BeepID）與 [`tools/convert_sound_to_pcm.ps1`](../tools/convert_sound_to_pcm.ps1) 拖曳轉檔。
- **跨機型實測**：已於 **Sony ILCE-6400 (FW 2.00)**、**Sony ILCE-6100**（感謝 ASFC-CYJ）與 **Sony ILCE-6600**（感謝 子康）實機成功開機點亮並完成套色轉檔驗證。

## V3.9 SSLF 實機與主機基準（`package=7ec416fa937fab67`）

- **`/etc/a6400-autoexec.so` 自掛載備援 ＋ 開機條件釐清**：開機掛勾與 `bootstrap-local.sh` 於 `/tmp_bt` 為唯讀時會自動掛載 `size=2048k tmpfs`（失敗時寫入 `/tmp/a6400-hook-err.log`）；同時跨批實機確認仍**必須保持相機 `藍牙功能 = 開`（飛航模式 = 關，無需配對手機）與 `觸控操作 = 開`**，開機才會由藍牙啟動鏈觸發 `/etc/ld.so.preload`。
- **`picojpeg.c` 32-bit 位元緩衝與 `rt.c` 字組 `memset`**：無須 NEON，主機測試 `A6409675-original.JPG` 6MP `decode_ms` 由 `249 ms` 降至 `138 ms`，輸出 JPEG 與前代 100% 位元一致；實機 `A6409868.JPG`（`portra_400 grain=2 halation=1` `1.7MP`）實拍計時 `read=1350ms`、`render=3140ms`（`decode_ms=1166`, `film_ms=496`, `encode_ms=1147`）、`commit=1240ms`、總計 **`total_ms=6690` (`result=0`, `target_verified=1`)**。
- **多組自訂快門音效（24 kHz Sony SDS 32-byte ADPCM）**：已驗證三組 `MS_BIND`（`29,760 B` / `24,768 B` / `18,560 B`）可於實機正常掛載切換；記憶卡 `/A6400/CHARO.PCM`（或 `SHUTTER.PCM`、`1–29,760 B` 之 24 kHz SDS ADPCM）亦可於開機基線完成後安全覆寫 RAM 音效（選單顯示 `SD自訂`）。
- **選單即時轉檔與 `1,024` 佇列顯示**：透過 `a6400_ui_status_v1`（不影響 `sizeof(ui)==1120` ABI）於頂部標題與「膠片細節」底欄顯示已轉張數與佇列進度。
- **穩定性、`/dev/nflasha10` Inode 保護與 PMCA 熱切換修正**：`CAPTURE_WAIT_MS=4000u`、`CAPTURE_BASELINE_INTERVAL_MS=750u`、`CAPTURE_STABLE_MS=800u`、略過非錯誤 `[AVIMMGR]`/`[MprCnv]` 雜訊、修正 `RAM_JOB_READ_RETRY` 後殘留 `uncertain=1` 誤停；`scan == -2`（`media_unavailable`）主動 `transport_stop` 釋放 `mpr_monio.elf`（實機冷開機後直接插 USB 執行 `--diag` 免放 `/disable_hook` 即一次從 `054C:0CA8` 切進 `054C:0336`）；`pmca_deploy_v3_clite.py` 全命令 `<= 180` 字元、掛載 `/tmp_bt/v3c_up` `2048k tmpfs`、保留 `/etc` 與 `/tmp` 共用之 `/tmp/a6400-autoexec.so`，並提供 `--rollback` 與 `--diag`。

## 已驗證的實機結果（V3.5.1 Fast SP）

- **強化浮層觸控選單（`MENU + 放大鏡` 長按 2 秒召喚）**：
  - 採用半透明深色浮動卡片、頂部 Sony Alpha 橘條與繁體中文介面（使用相機原生字型 `0x02076000`）。
  - 主選單（`FILM_MENU_HOME`）配置：`LUT 濾鏡`（開/關）、`膠片風格`（雙頁 10 款）、**`膠片細節`**（點入調節顆粒/光暈）、（有提供音效時顯示）`快門聲`、左下角 **`畫質: 1.7MP 極速 / 6MP 高清`**，以及右下角 `關閉`。
  - **「膠片細節」子分頁（`FILM_MENU_DETAILS`）**：
    - `顆粒強度`：`0`（`無 (加速)`）／`1`（`輕微`）／`2`（`標準`）／`3`（`濃厚`）循環切換。
    - `底片光暈`：`開啟`／`關閉 (加速)` 切換（關閉時直接略過 `film_mask_blur` 與光暈遮罩記憶體 `mask_kib=0`）。
    - `恢復細節預設`：一鍵重設回 `grain=2, halation=1`。
- **左下角即時進度提示條（Toast HUD）**：
  - 保持 `sizeof(ui) == 1120` 快照 ABI 不變，透過獨立 `a6400_ui_toast_v1`（magic `0x54534f54`）顯示：偵測新照 → 橘色 `處理中: ...`、寫卡完成 → 綠色 `OK 已存SD: ...`（顯示約 3.5 秒自動隱藏）、驗證失敗（如 `source_size` 安全中止）→ 紅色錯誤提示，絕不干擾正常拍照與原片保存。
- **雙模式處理速度實測演進（Sony A6400 實機實拍）**：

- **已讀取實機 CPU 規格（`/proc/cpuinfo`）**：
  - `ARMv7 Processor rev 1 (v7l)`、`CPU part: 0xc05`（Cortex-A5 四核）
  - `Features: swp half thumb fastmult vfp edsp vfpv3 vfpv3d16 tls vfpv4`
  - **確認不含 ARM NEON SIMD**（編譯參數維持 `-mcpu=cortex-a5 -mfpu=vfpv3-d16 -mfloat-abi=hard`）。
- **寫卡與檔案系統相容性**：
  - 開機期 `native_sd_read=0`（不掛載 SD 卡），拍後透過 Sony 原生 `mwf_monio` `IFSYS` 存取動態解析之 `B:/` 或 `A:/` SD 卡路徑；**`FAT32` 與大容量 `exFAT`（含 64GB / 128GB SDXC）皆可正常使用**。
- **自動掃描穩定性**：
  - 背景守護行程（`FILM_CAPTURE_PERSISTENT=1`）佇列容量為 **`1024`**（只掃描最新 DCF 目錄 `latest_dcim_dir` + `mmc0` 中斷喚醒）。

## 目前限制與操作注意事項

- **必開開關與首次喚醒條件**：務必開啟相機 **`藍牙功能 = 開`（飛航關）＋ `觸控操作 = 開`**；冷開機等待 **10–15 秒** 後看到右上角 **`V4.3 SLEM 已就緒`** 提示或**輕觸螢幕並放開一次**，再長按 `MENU + 放大鏡` 2 秒即可喚出選單。
- **設定保存位置**：目前實作將預設、顆粒、光暈、雙重曝光與音效槽位維持在 RAM 內，**關機或拔電池重開後會回復初始預設（`LUT: 關閉`、`Portra 400`、`grain=2`、`halation=1`、`1.7MP 極速`）**，不修改機身 NVRAM／設定分區；但已轉檔存入 `/A6400/TEST/` 的照片與 `/A6400/SOUNDS/` 自訂音檔皆永久保存於記憶卡，重開後可於「套色相冊」與 Sound Deck 直接讀取。
- **目錄與檔案容量限制**：
  - 記憶卡根目錄須手動先建好空資料夾 **`/A6400/TEST/`**（輸出 `FxxxxNNN.JPG` 不會寫入相機播放資料庫 `AVF_INFO`）。
  - 最新單一 DCF 資料夾 `.JPG` 與 `/A6400/TEST/` 相冊索引上限各為 **`1,024`** 張；單張原始 `.JPG` 上限 **`16,711,680` bytes（`15.94 MiB`）**（`tmpfs` 上限 `32 MiB` 減去工作空間）。
  - **V4.3 Sound Lite** 自訂 `/A6400/SOUNDS/*.pcm` 最多載入 **12 個** 檔案（UTF-8 檔名 `<= 44` bytes、須為 Sony 24 kHz 32-byte SDS ADPCM、`<= 29,760` bytes）。
- **卸除／回滾需求**：程式執行於 `/tmp_bt` 記憶體，但不影響原廠開機；若日後需要清除 `/etc/ld.so.preload` 或切換回滾包，**需透過 USB 連接進入 Sony 服務模式（PMCA）執行回滾或停用指令**。
- **不支援項目**：即時取景 Live View LUT 預覽、RAW 檔案處理、錄影套色、或運行期間任意匯入 `.cube` 檔。

## 測試界線
