# 發布與公開版檢查記錄

## V3.5.1 Fast SP（2026 年 11 月 19 日）

- 同步自實機驗證通過之 **V3.5.1 Fast SP**（`package=5b079b295c2a7a27`）全部原始碼與工具腳本。
- 將「1.7MP / 6MP 畫質切換」與主標題從 `#ifdef A6400_CHARO_SHUTTER` 解耦，並更新 [`tools/build_v3_clite.sh`](../tools/build_v3_clite.sh)，使沒有私人快門音檔的公開編譯環境亦可直接產出完整 V3.5.1 Fast SP 功能。
- 修正舊文件過時描述：更新佇列容量上限（`128 → 1024`）、`exFAT` 原生相容說明、移除過時的「未附五款濾鏡實作」矛盾段落，並誠實標註 `/etc/ld.so.preload` 清除需透過 USB PMCA 服務模式。
- 補充完整工程與效能分析文件 [`docs/開發與架構細節.md`](開發與架構細節.md)。
- 驗證紀錄：
  - 開發電腦端 `python3 -m unittest discover -p 'test_*.py' -v` 與 `python3 tools/check_public_tree.py` 全數通過。
  - 交叉編譯機端（ARM hard-float `a6400-film-boot-v15.tar` = `194,560 B <= 196,608 B`）與 Sony ILCE-6400 FW 2.00 實機冷開機實拍驗證通過（`1.7MP`: `5,650~5,950 ms`、`6MP`: `17,490 ms`）。
