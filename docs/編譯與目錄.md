# 編譯與目錄說明

## 先執行不接相機的測試

需求為 Python 3.10 以上、`cc` 及 POSIX shell。公開測試使用 Python 標準函式庫，不需要 Pillow、NumPy、Sony 函式庫或相機。

```sh
python3 -m unittest discover -p 'test_*.py' -v
python3 tools/check_public_tree.py
```

測試會在系統暫存目錄編譯 C 程式並執行，涵蓋：
- 選單與觸控邏輯（含 `FILM_MENU_HOME`、`FILM_MENU_STOCKS`、`FILM_MENU_DETAILS`、2×2 田字格與三段畫質／雙重曝光控制）
- `a6400_ui_toast_v1` Toast HUD、1120-byte `a6400_ui_state` 快照 ABI、`a6400_ui_v4_v1` V4 擴展結構與 OSD `RGBA4444` blitter 驗證
- V4.3 套色相冊索引／16 槽位快取／EXIF 轉正、V4.3 Sound Lite 16 槽位與 SDS ADPCM 波形／白名單檢驗
- 合成設定快照、派工 gate、原生回覆解析、背景守護行程協調與套件雜湊組裝驗證

## 相機端交叉編譯需要的本地輸入（公開倉庫不含 Sony 原廠檔）

相機端建置腳本使用 ARM hard-float 交叉工具鏈（`-mcpu=cortex-a5 -mfpu=vfpv3-d16 -mfloat-abi=hard`，實機 Cortex-A5 **不含 NEON**），並對 Sony 原廠 libc／monitor 做雜湊釘選。這些原廠專有二進位檔不可提交到 Git，需開發者從自己的 A6400 FW 2.00 合法拉取：

- `<camera-libs>/libc-2.11.2.so` 與 `libdl-2.11.2.so`
- `camera-mpr_monio.elf`（FW 2.00 原版 `mpr_monio.elf`）
- `camera-mwf_monio.elf`（FW 2.00 原版 `mwf_monio.elf`）

執行編譯：

```sh
# V4.3 SLEM 完整版（A6400_MTF2_ENABLE=0 為 WithNoTouch；A6400_UI_LANG_SC=1 為簡體中文）
sh tools/build_v3_clite.sh \
  /path/to/camera-libs \
  /path/to/camera-mpr_monio.elf \
  /path/to/camera-mwf_monio.elf \
  ./build-v43-slem

# 或 V4.3 Sound Lite 純淨快門音分支
sh tools/build_sound_lite.sh \
  /path/to/camera-libs \
  /path/to/camera-mpr_monio.elf \
  /path/to/camera-mwf_monio.elf \
  ./build-sound-lite
```

- **可選私人音效擴充**：若自行準備 `<= 29,760` bytes Sony 24 kHz SDS ADPCM `.pcm` 置於 `assets/a6400-charo-shutter.pcm`，`build_v3_clite.sh` 會自動啟用 `A6400_CHARO_SHUTTER=1` 並一同打包 `charo_bind.c`；若無該檔案則自動切換 `A6400_CHARO_SHUTTER=0` 純靜音模式，**`1.7MP / 6MP / 12MP` 畫質切換、雙重曝光與「細節設定」均正常保留**。
- **套件大小上限**：`build_film_local_boot_package.py` 強制檢查 `a6400-film-boot-v15.tar <= 196,608` bytes（V4.3 起採 `gzip` 壓縮後約 `116–120 KB`，Flash 與傳輸體積大幅低於上限）。
